# Book Chosen

- Title: *Working Backwards*
- Authors: Colin Bryar, Bill Carr
- Intention: Turn vague product ideas into customer-first decisions using PR/FAQ.

# Distilled Notes Used for This Skill

1. Start from the customer problem, not the internal solution.
2. Write a future press release first to force clarity of value.
3. Use FAQ to surface hard questions early across product, engineering, operations, and legal.
4. Keep documents decision-oriented with explicit metrics and trade-offs.
5. Use written narratives to improve alignment and review quality.
