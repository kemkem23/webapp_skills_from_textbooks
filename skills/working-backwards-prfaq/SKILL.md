# Working Backwards PR/FAQ Skill

Execute one intention only: convert a product idea into a decision-ready PR/FAQ.

## Required Input

Collect these minimum inputs before drafting:
- Primary customer segment
- Top customer pain point
- Current alternative or workaround
- Expected customer outcome
- Business goal for the launch

If any item is missing, state assumptions explicitly.

## Workflow

1. Draft the Press Release first.
   - Use `assets/prfaq_template.md` section order.
   - Write for customers, not internal teams.
   - Put the customer outcome in headline and opening paragraph.

2. Draft the FAQ second.
   - Fill both external and internal FAQ sections.
   - Make each answer concrete with policy, metric, or boundary.

3. Add decision mechanics.
   - Define 3–5 measurable success metrics.
   - List key risks and mitigation owners.
   - Finish with explicit go/no-go criteria.

4. Run quality review.
   - Evaluate against `references/quality_checklist.md`.
   - Revise until all checklist items pass.

## Output Constraints

- Keep the press release between 400 and 700 words.
- Keep FAQ answers concise and specific.
- Mark uncertain statements as assumptions.
- Include a short validation plan for each critical assumption.
